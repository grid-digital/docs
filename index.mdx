Use the Cconnect Customer API to synchronize support tickets, read conversations and messages, and discover your company's connected channels.

The API uses HTTPS, JSON, versioned resource paths, and company-owned bearer credentials. Each request is restricted to the company that issued its credential. Your credential's scopes and your company's product entitlements determine which operations you can use.

## What you can integrate

| Product | Supported operations in v1 |
| --- | --- |
| Desk | List, retrieve, create, and update tickets; read custom ticket fields and email channel metadata |
| Chat | Read conversations, message history, and WhatsApp channel metadata |
| Integration | Inspect your credential's company, scopes, and current products |

Creating an API ticket does not send a message or email. Outbound sends, customer webhooks, bulk deletion, member administration, contact CRUD, and Call APIs are outside this release.

## Start here

- Follow the [quickstart](/quickstart) for your first request.
- Ask your company administrator for a credential with the appropriate [scopes](/authentication).
- Open the **API reference** tab for endpoint schemas and examples.
- Download the [generated OpenAPI specification](/openapi.json).

## Addresses and availability

The developer portal is `https://developers.cconnect.online`. The specification is configured for the API origin `https://cconnect.online`; your Cconnect deployment administrator must confirm that this origin routes `/api/v1` to the updated Omni API before onboarding integrations.

The customer API is disabled by default on the backend. These documents describe the v1 implementation; publication alone does not activate it. If a request returns `503 api_disabled`, ask your Cconnect deployment administrator to enable customer API access.

The resource-oriented reference follows conventions familiar from [Freshdesk](https://developers.freshdesk.com/api/) and [Qontak](https://docs.qontak.com/). Cconnect defines its own authentication scheme and supported operations.
